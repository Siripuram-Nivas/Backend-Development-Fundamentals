# Backend Development Fundamentals

This repository contains lab assignments and projects for Backend Development Fundamentals:

## Labs Included

1. **[Node_js_and_Express_server lab1](./Node_js_and_Express_server%20lab1)**
   - Initializing Node.js project and setting up Express server
   - Basic routing, HTTP methods, and status codes

2. **[SQLite-database-and-CRUD-routes-Lab2](./SQLite-database-and-CRUD-routes-Lab2)**
   - SQLite database integration
   - CRUD API endpoints for managing resources
   - Error handling and database query execution

3. **[REST-API-query-parameters-validation-debugging-lab3](./REST-API-query-parameters-validation-debugging-lab3)**
   - REST API design with query parameters (filtering, sorting, pagination)
   - Input validation and sanitization
   - Error handling and API debugging
